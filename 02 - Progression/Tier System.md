# Tier System

**Tier is the setting's primary public measure of realized current power.** It is determined by the development of the vessel through attributes, not by Level.

Each Tier contains four substages:

**Beginner → Intermediate → Advanced → Peak → breakthrough to the next Tier**

A character may be called an **Advanced Elite**, **Peak King**, **Beginner Sovereign**, etc.

## Interpretation

- **Ordinary** describes mundane humanity.
- **Iron** is the first clearly superhuman vessel.
- Each major Tier breakthrough should be more than arithmetic; it represents a qualitative reconstruction/refinement of the body.
- Higher-Tier stats increasingly represent the capacity to contain enormous Mana, bloodline power and Divinity.
- Tier breakthroughs may themselves grant significant stat growth because the vessel is reconstructed.

## Specialized builds

A mage and warrior in the same Tier do not need equal stats. Tier qualification must allow specialization.

## Tier vs Rank

**Rank:** how efficiently you can progress.  
**Tier:** how far you have actually progressed.

An SS-Rank Iron is weak compared with a C-Rank King in current combat power, even though the SS-Rank being has far greater long-term potential.
