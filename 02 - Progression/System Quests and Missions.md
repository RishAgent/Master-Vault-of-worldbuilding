# System Quests and Missions

The System can actively generate **Quests** and **Missions** to guide, test or accelerate progression.

## Possible purposes

- teach new System mechanics
- push a user toward a breakthrough
- unlock progression beyond a level checkpoint
- reward exploration or Gate clearing
- encourage class development
- create trials around unusual achievements
- introduce world-scale objectives later

## Reward categories

Depending on difficulty and context, rewards may include:

- EXP
- attribute growth
- System currency / Tower Points (if retained)
- items
- consumables
- skill scrolls
- class-related opportunities
- rare materials
- titles
- traits
- access to trials, gates, areas or shops

## Design principle

Quests should not replace character agency. They are System-generated opportunities/pressures, not a script that controls every action.
