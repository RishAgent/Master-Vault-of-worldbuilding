# Star & Circle Progression System — V4 Canon

> **Purpose:** Canon reference for the redesigned Star/Circle magic architecture.  
> This framework is separate from Tier, Level, Personal Rank, Class, Race, and Affinity.

---

# 1. Core Principle

## Star Rating

A **Star** represents the architecture, compression, throughput, and complexity of a Mana Core.

Star Rating determines:
- Mana Core complexity
- Mana compression
- Mana throughput
- spell stability
- spell complexity
- external Mana control
- control radius
- large-scale spell capability
- access to higher Circles
- efficiency of advanced magic

Star Rating does **not** directly equal:
- Tier
- Level
- Personal Rank
- Class rarity
- combat strength

A warrior can possess a high Tier with a relatively low Star Rating.

A mage can possess unusually advanced Stars for their Tier.

# 3. Base INT vs Effective INT

Star progression checks **Base INT only**.

The following do **not** count toward Star advancement requirements:
- equipment bonuses
- title bonuses
- temporary buffs
- temporary transformation bonuses
- Skill-based Attribute increases
- borrowed Mana
- external magical amplification

These can still improve:
- practical spell damage
- current Mana capacity if the effect explicitly modifies usable INT
- control
- combat output
- regeneration

But they cannot create a new natural Star.

## Example — Alok

Current Base INT:

**825**

Title-adjusted INT:

**990**

Ring-adjusted combat INT:

**1,040**

However, Star progression reads:

# **825 Base INT**

Second Star requirement:

# **1,000 Base INT**

Therefore Alok remains:

# **★ One Star**

until his natural/base INT reaches 1,000.

# 7. Natural Star Formation

Natural Star formation requires:

1. meeting the full Base INT requirement
2. sufficient Mana Core stability
3. enough Mana-control mastery
4. successful Circle construction

A natural Star grants:
- full throughput
- full stability
- normal Mana efficiency
- normal future progression
- no structural penalty

Natural formation is the ideal progression route.

---

# 8. Artificial Star Formation

A Star can be forced before reaching the natural INT requirement.

The standard minimum is approximately:

# **75% of the natural Base INT requirement**

Artificial Star formation may require:
- rare Mana Crystals
- Monster Cores
- Tower resources
- Star-forming elixirs
- magical formation arrays
- powerful external assistance
- specialized Class abilities
- high-grade artifacts

Artificial Stars begin incomplete.

Possible penalties:
- increased Mana cost
- lower throughput
- reduced spell stability
- greater chance of Circle collapse
- increased difficulty forming the next Star
- risk of Mana Core injury
- poorer Mana compression

When natural Base INT later reaches the true requirement, the artificial Star can be completed and stabilized.

# 9. Spell Control Radius

The original "Range" value is now interpreted as:

## Stable Control Radius

The approximate radius within which a mage can maintain high-quality external Mana manipulation without major degradation.

It is **not** the maximum travel distance of every projectile.

A spell projectile can travel beyond this radius if its structure allows it.

---

# 10. Large-Scale Effect Width

The original "Width" value is now interpreted as:

## Major Area-of-Effect Width

A rough benchmark for the scale of a large, properly controlled spell at that Star.

This is not a mandatory spell size.

A mage can use:
- much smaller precision spells
- narrow beams
- focused attacks
- larger but less stable effects

# 18. Canon Summary

## Locked rules

- **1 Base INT = 100 Mana**
- Star advancement checks **Base INT**
- temporary/equipment/title INT does not satisfy Star thresholds
- each Star forms one corresponding Circle
- One Star begins at **250 Base INT**
- Two Stars begins at **1,000 Base INT**
- later Stars scale approximately ×5 in Base INT requirement
- Artificial Stars can begin at roughly **75%** of natural threshold
- Star Rating is separate from Tier
- Star Rating controls magical architecture, not raw combat Rank
- WAHO currently knows almost nothing about Stars
- Alok is currently **One Star**
- Alok will reach **Two Stars during the Trials**
- old Mage titles remain, but are separate from Star Rating
- theoretical framework currently extends to **24 Stars**
