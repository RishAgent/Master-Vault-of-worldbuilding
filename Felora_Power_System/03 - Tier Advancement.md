# Felora Tier Advancement

Felora uses the same universal advancement method as Tower-connected Players.

# Stat Saturation
→
# Merit Qualification
→
# Advancement Quest / Diagnosis
→
# Gather Required Resources
→
# Break Resources into Mana and Essence
→
# Reconstruct Vessel
→
# Next Substage / Tier

Tower-connected Players receive explicit System quests.

Felorans discover equivalent requirements through advancement halls, guild appraisers, academies, alchemists, family techniques and magical instruments.

## Resource Rule
To advance within a Tier, resources normally need to be at least the quality of the current substage.

| Advancement | Minimum Normal Resource Quality |
|---|---|
| Beginner Bronze → Intermediate Bronze | Beginner Bronze+ |
| Intermediate Bronze → Advanced Bronze | Intermediate Bronze+ |
| Advanced Bronze → Peak Bronze | Advanced Bronze+ |
| Peak Bronze → Beginner Silver | Peak Bronze+ plus Silver keystone |
| Beginner Silver → Intermediate Silver | Beginner Silver+ |
| Intermediate Silver → Advanced Silver | Intermediate Silver+ |
| Advanced Silver → Peak Silver | Advanced Silver+ |
| Peak Silver → Beginner Gold | Peak Silver+ plus Gold keystone |

## Major Tier Breakthroughs
Major breakthroughs are far harder than substage advancement and normally require:
- much higher Lifetime Merit
- multiple Peak-current-Tier cores
- large quantities of crystals
- rare medicines
- compatible catalysts
- at least one next-Tier keystone material
- better formations/chambers
