# 1. Scaling Rules Used for This Update

The update is applied in three layers.

## Layer One — Intermediate Silver Breakthrough

Crossing from Beginner Silver into Intermediate Silver grants:

- **+250 STR**
- **+250 AGI**
- **+250 VIT**
- **+250 INT**
- **+250 Divinity**

All existing working Skill and Spell outputs then receive:

# **×1.25 Intermediate-Silver scaling**

This represents the stronger vessel, denser Mana, improved channels, and higher substage.

## Layer Two — Fourfold Racial Vessel Reinforcement

After the substage breakthrough, the developing Dragon / Demon / Angel / Valkyrie vessel provides an additional:

# **×1.20 general output reinforcement**

This applies after the Intermediate-Silver increase.

Combined general multiplier:

# **1.25 × 1.20 = ×1.50**

This multiplier applies before recalculating affinity-dependent damage.

> [!note]
> Alok's existing **Child of Life and Death +20% effective Attribute title bonus** remains separate.
>
> The racial **×1.20 output reinforcement** is not another +20% Attribute multiplier.

## Layer Three — Affinity Recalculation

Old working spell values already included their previous affinity states.

Therefore the new +250% to +350% affinity values are **not simply added again** to the old damage.

Affinity-dependent Skills are recalculated using the ratio between the old effective affinity multiplier and the new one.

This prevents accidental double-counting.

# **Thrown Artifact Output = Physical Delivery + Magical Payload + Artifact Conduction**

4. resolve the final attack as one hybrid event rather than multiplying every component together.

This prevents artificial exponential scaling while allowing Alok's hybrid war-mage build to matter fully.
