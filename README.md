# Master Vault of Worldbuilding

This repository is the authoritative canon and continuity reference for the Alok V4 worldbuilding project.

## Canon policy

- Treat the current vault notes as the master reference for lore, progression, characters, systems, timelines, and continuity.
- Material under `99 - Legacy Reference/` is retained for historical comparison and is not automatically current canon.
- Material under `09 - Design Queue/` and files explicitly marked as plans, drafts, open decisions, or proposals remain provisional until canonized.
- When two notes conflict, prefer the more recent explicitly canonized note and record the resolution in the appropriate canon summary or continuity note.

## Opening the vault

Clone or download the repository, then open the repository folder itself as an Obsidian vault.

Start with [`00 - Start Here/Home.md`](00%20-%20Start%20Here/Home.md).

## Repository hygiene

Stable Obsidian settings are versioned. Device-specific workspace layouts, caches, and trash are ignored to prevent noisy conflicts.
