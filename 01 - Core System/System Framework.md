# System Framework

The System tracks multiple independent axes of growth. No single number should describe the entirety of a being.

## Primary progression axes

| System | Meaning |
|---|---|
| **Personal Rank** | Innate/realized growth potential and growth efficiency |
| **Tier** | Current qualitative strength of the vessel, determined by stats |
| **Level** | Accumulated System progression and a source of growth |
| **Class** | Specialization/path; improves some forms of growth and skill use without hard-locking others |
| **Star Rating** | Development of the mana core/circles and spell-processing architecture |
| **Attributes** | Direct measurable capabilities of the vessel |
| **Race** | Starting baseline, racial traits, lifespan, natural stat biases and evolution |
| **Traits** | Individual modifiers or unusual characteristics |
| **Bloodlines** | Inherited or awakened lineage powers and growth influences |
| **Divinity** | Divine energy/quality; separate from Mana and ordinary attributes |
| **Laws / Authority** | Higher-order progression used much later in the story |

## Core relationships

**Rank → growth efficiency**  
**Race → baseline + natural growth distribution**  
**Class → specialization + class growth/skill efficiency**  
**Level → recurring growth opportunities**  
**Stats → determine Tier**  
**Stars → determine mana-processing architecture and stable spell complexity**  
**Divinity → enables divine evolution and eventually the Ninth-Star God Vessel**

## System philosophy

The System does not need to hard-lock everything. It should measure and formalize what a being is becoming while still allowing exceptional beings to violate normal expectations through talent, bloodline, artifacts, training, sacrifice, or unusual evolution.
