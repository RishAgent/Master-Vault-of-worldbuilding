# Status Window

The System Status should show, at minimum:

1. **Name**
2. **Race**
3. **Level**
4. **Personal Rank**
5. **Tier**
6. **Star Rating**
7. **Traits** — if any
8. **Special Bloodlines** — if any
9. **Class / Classes**
10. **Skills**
11. **Attributes**
12. **Mana**
13. **Divinity** — only where applicable / awakened / innate
