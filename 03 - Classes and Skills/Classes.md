# Classes

Classes are **specializations and evolutionary paths**, not permission systems.

## Core rule

A Class does **not** prevent a character from learning unrelated skills.

A fire-oriented class can still use:

- Nature Bind
- sword skills
- healing
- earth defenses
- movement skills
- physical reinforcement

provided the character possesses the skill and can satisfy its requirements.

## What Classes do

Classes can provide:

- favored stat-growth distribution
- skill efficiency
- reduced mana cost for aligned techniques
- higher damage/effectiveness for aligned abilities
- faster proficiency growth
- class passives
- class-exclusive or class-evolved abilities
- access to specialized evolutions

Thus:

**Skills determine what you can do.**  
**Class determines what you are especially efficient at becoming.**

## Evolutionary classes

Classes should evolve based on actual development rather than remain static forever.

Example concept:

`Storm Initiate → Lightning Adept → Heavenbolt Magus → higher unique evolution`

A user who develops the same affinity through physical combat could evolve in a completely different direction.

Hybridization/synthesis should be possible where the character's development genuinely supports it.

## Off-class skill use

An off-class skill is not forbidden. It may simply be:

- more expensive
- less powerful
- slower to master
- limited by affinity or mana architecture

A character with the appropriate affinity, Trait or Bloodline can overcome those disadvantages.
