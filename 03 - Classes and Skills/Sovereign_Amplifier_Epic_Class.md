# Sovereign Amplifier — Epic Class

## 1. Class Origin

Alok first encountered the base form of this Class during Round I of the Starlight competition.

The opposing contestant possessed:

> **Power Amplifier — Rare**

The Class specialized in strengthening allies and increasing the output of spells that passed through dedicated amplification circles.

Alok's Class Codex analyzed the Class during battle, reconstructed its architecture, and produced a superior version:

> **Sovereign Amplifier — Epic**

The Codex did not simply copy the original Class.

It rebuilt and improved the underlying support architecture.

---

# 2. Core Concept

The Sovereign Amplifier is a dedicated **force-multiplier support Class**.

Its purpose is not primarily direct offense.

Instead, it improves:

- allied physical capability
- allied magical capability
- allied Mana recovery
- spell output
- formation efficiency
- artillery strength
- barrier strength
- healing strength
- support-network performance

Its true value increases dramatically when used inside:

- organized parties
- military formations
- Shadow armies
- the Eternal Legion
- coordinated mage groups

---

# 3. Star and Circle Integration

The Class is directly constrained by the user's existing **Star and Circle architecture**.

A Star represents completed Mana-Core architecture.

Each Star provides:

- 1 permanent Core Circle
- 1 normal independent projected Casting Circle

Therefore:

> **The Class ceiling does not grant circles the user does not possess.**

A one-Star Sovereign Amplifier can normally use only one amplification circle.

A three-Star Sovereign Amplifier can normally use three.

A ten-Star Sovereign Amplifier may eventually use the full ten-circle Class ceiling.

The Class therefore scales naturally with progression instead of bypassing it.

---

# 4. Important Distinction

## Star Capacity

Determines:

> **How many circles the user can actually manifest and control.**

## Class Architecture

Determines:

> **What those amplification circles are capable of doing.**

A normal three-Star mage may have three projected Casting Circles.

A three-Star Sovereign Amplifier also has three—

but those circles can be specialized as amplification structures.

---

# 5. Base Class — Power Amplifier

## Rarity

> **Rare**

## Core Reinforcement

The base Class can grant an allied target approximately:

- **+30% Physical Capability**
- **+30% Magical Capability**
- **+30% Mana Recovery**

This is a broad reinforcement effect rather than a simple STR-only or INT-only buff.

---

# 6. Rare Amplification Circle

Each compatible spell that passes through one amplification circle gains:

> **+50% of the spell's original output**

The amplification is additive to the original spell output.

It is **not recursively multiplicative** between circles.

### Examples

Base spell:

> 100,000 AP

One amplification circle:

> 150,000 AP

Two circles:

> 200,000 AP

Three circles:

> 250,000 AP

Five circles:

> 350,000 AP

---

# 7. Rare Class Ceiling

The normal Power Amplifier Class can support a maximum architecture of:

> **5 Amplification Circles**

However, this is only the Class ceiling.

The actual user may still be limited by Star Rating.

Examples:

Available circles:

> 1

Maximum practical spell amplification:

> **×1.5**

### Two-Star Power Amplifier

> 2

### Three-Star Power Amplifier

> 3

> **×2.5**

### Five-Star Power Amplifier

---

# 8. Tier and Spell Compatibility

Amplification is not completely unrestricted.

The base Rare Class can normally amplify spells that are:

- from the same Tier as the Amplifier
- the same or lower substage
- up to approximately one substage higher under stable conditions

The Amplifier still requires sufficient:

- Mana throughput
- Circle stability
- control
- Star architecture
- spell compatibility
- Class mastery

The Class does not allow a low-Tier support user to freely amplify vastly superior high-Tier magic.

---

# 9. Epic Reconstruction — Sovereign Amplifier

Alok's Class Codex reconstructs the Rare Class into:

# **SOVEREIGN AMPLIFIER — EPIC**

The Epic form significantly improves both the ally reinforcement effect and the amplification-circle architecture.

---

# 10. Sovereign Reinforcement

A target receiving the Class's major reinforcement effect gains:

- **+100% Physical Capability**
- **+100% Magical Capability**
- **+100% Mana Recovery**

This does not automatically create new Stars, Core Circles, racial structures, or Tier advancement.

It enhances the target's current realized capability.

---

# 11. Sovereign Amplification Circle

Each compatible spell passing through one Sovereign Amplification Circle gains:

> **+100% of the spell's original output**

This remains additive to base spell output.

It is not recursive circle-on-circle multiplication.

# 14. Why the 10-Circle Ceiling Is Not Overpowered by Default

The Class is naturally restrained by the setting's progression system.

A user must actually possess the Star architecture required to manifest the circles.

Higher Stars require exponentially greater Mana-Core development and Base INT.

Therefore:

- a low-Star user may only possess one usable circle
- a developing Bronze may possess one or two
- a stronger Bronze or Silver may possess two or three
- very advanced beings may eventually reach much higher counts
- the ten-circle ceiling belongs to extremely advanced Star architecture

The Class does not bypass the Star system.

It rewards progression through it.

# 21. Multiple Amplifier Rule

Multiple Amplifiers may cooperate.

However amplification remains within one additive amplification layer.

The intended rule is:

> **Amplification bonuses add to the original spell output rather than recursively multiplying one another.**

Example:

Base spell:

> 100,000 AP

Five Sovereign circles:

> +500%

Three additional compatible Sovereign circles from another source:

> +300%

Final:

> 100,000 × 9 = **900,000 AP**

Not:

> 100,000 × 6 × 4

This prevents uncontrolled exponential stacking.

---

# 22. Spell Structure Still Matters

Amplification increases output.

It does not automatically fix poor spell construction.

A spell must remain compatible with:

- its caster's Tier
- its Star complexity
- Mana throughput
- structural stability
- the Amplifier's Tier
- the Amplifier's Star architecture

Higher-quality spell construction benefits more from heavy amplification because it is better able to preserve stability.

The Sovereign Amplifier is not meant to be a conventional damage dealer.
