# Skills and Magic

## General rule

Skills are broadly learnable if the user has the required knowledge, affinity, item/scroll, Class interaction, physiology or other prerequisite.

Classes **enhance** skills; they do not normally hard-lock unrelated skills.

## Skill sources

Possible acquisition paths:

- natural learning/training
- System-awarded skill
- skill scroll
- Class skill
- racial skill
- bloodline skill
- Trait evolution
- teacher/manual
- monster drop
- quest reward
- self-created technique
- Law/Authority manifestation much later

## Skill descriptors

A skill may eventually track some combination of:

- skill name
- skill grade/rank
- Star requirement for magic
- active/passive
- affinity/element
- mana cost
- proficiency/mastery
- cooldown where appropriate
- Class/Race/Bloodline synergy
