# Class System — Rarity, Growth, Stages, Evolutions

> [!important] Canon update
> This note replaces the older working idea that first Class Awakening occurs around Level 25.
>
> In current V4 canon, a **Classless individual is capped at Level 5**.  
> A **Judgment Fragment** initiates the first Judgment Trial, and the result determines the character's first Class path.

---

# 1. Core Principle

A **Class** is a specialization and evolutionary path created from what a person has become.

It reflects:

- Personal Rank
- Race
- Affinities
- Bloodlines
- Traits
- Attributes
- Skills
- combat style
- repeated behavior
- achievements
- choices
- professions
- Tier
- Star Rating
- Judgment performance
- hidden System conditions

A Class does **not** function as a permission system.

A Fire Mage can still learn swordsmanship.  
A swordsman can still learn healing.  
A Guardian can still learn lightning magic.  
A mage can still use physical reinforcement.

The difference is **efficiency and specialization**.

> **Skills determine what a person can do.**  
> **Class determines what they are especially good at becoming.**

---

# 2. What a Class Provides

A Class may provide some combination of:

- bonus Attributes per Level
- specialized stat distribution
- improved Skill damage/effectiveness
- reduced Mana or Stamina costs
- improved Skill mastery gain
- improved affinity conversion
- Class-exclusive Skills
- Class Passives
- weapon compatibility
- casting-speed improvements
- defensive modifiers
- elemental resistance
- regeneration/recovery bonuses
- unique combat mechanics
- Class Quests
- branching evolutions
- hybrid evolutions
- unique breakthrough conditions
- Law/Domain compatibility at higher stages

Not every Class grants all of these.

A Common Class may primarily give modest stat growth and one passive.

A Legendary Class may fundamentally alter how the user's Mana, Skills, or body functions.

---

# 3. Class Growth Is Separate from Personal Rank

**Personal Rank** determines the individual's universal natural growth per Level.

**Class** adds specialized growth on top.

Example:

An S-Rank individual gains their normal S-Rank growth every Level.

If they possess a Fire Mage-type Class, they may additionally gain:

- INT
- AGI
- Mana-related bonuses

If they possess a Vanguard-type Class, they may instead gain:

- STR
- VIT
- defensive bonuses

Therefore two people with the same:

- Personal Rank
- Race
- Level
- Tier

can develop very differently because of their Classes.

---

# 4. Class Rarity

Class rarity describes the **quality, complexity, potential, exclusivity, and power ceiling of the Class path**.

It is not the same as:

- Personal Rank
- Tier
- Star Rating
- Skill Grade

## Current Class Rarity Ladder

| Rarity | General Meaning | Typical Initial Quality |
|---|---|---|
| **Common** | Basic specialization | Narrow, reliable bonuses |
| **Uncommon** | Refined specialization | Better growth and one or more meaningful mechanics |
| **Rare** | Advanced specialization | Strong synergy, stronger passives, better evolution routes |
| **Epic** | Exceptional path | Major mechanics, powerful Class Skills, strong growth |
| **Legendary** | Extremely rare path | Exceptional mechanics and high evolutionary ceiling |
| **Mythic** | World-class / civilization-class path | Can influence Laws, Domains, bloodlines, or large-scale combat later |
| **Unique** | Exists for one or extremely few individuals | Rules vary; may be weaker or stronger than Mythic depending on origin |
| **Divine** | Divine-level Class authority | Interacts naturally with Divinity, Laws, Domains, Authorities |

> [!note]
> **Unique** is not automatically stronger than Mythic.
>
> "Unique" primarily means the Class is singular or unprecedented.
>
> A Unique Class may begin weaker than a Legendary Class but possess an extraordinary evolutionary route.

# 5. Judgment and Class Rarity

The Judgment Trial does not simply roll a random Class.

The System has already been tracking the individual before the Trial.

It evaluates:

- combat history
- enemy Tier disparity
- Skill creation
- Skill combinations
- favored weapons
- protective behavior
- aggression
- efficiency
- affinity usage
- resource management
- achievements
- titles
- risk tolerance
- repeated decisions
- unusual feats
- Bloodline activity
- Race
- Personal Rank
- Tier
- Star Rating
- Traits

The **Trial adds more data**.

The better the person's performance and the more complete their recorded development, the more precise and extensive the Class selection becomes.

## General Judgment Principle

Poor performance:
- fewer options
- lower maximum rarity
- less specialized matches

Strong performance:
- more options
- higher-rarity paths
- more advanced specialization

Exceptional performance:
- hidden Classes
- hybrid paths
- unique branches
- Bloodline-linked Classes
- System irregularities

# 6. First Class and Level Cap

Current canon:

- Classless characters may Level normally until **Level 5**
- Level 5 is the **Classless Level Cap**
- EXP earned after the cap is **banked**
- Tier and stage advancement are **not** blocked by the Level cap
- training still works
- Attributes may still be increased where vessel capacity allows
- breakthroughs may still occur
- materials may still refine the vessel

A character can therefore enter Judgment stronger than the normal Level-5 baseline.

This matters because Judgment performance is partly dependent on the actual strength and development of the candidate.

---

# 7. Class Development Stages

A Class itself develops through **Class Stages**.

These are separate from Tier.

Current early progression terminology:

1. **Initiate**
2. **Apprentice**
3. **Adept**
4. **Expert**
5. **Master**
6. **Grandmaster**
7. **Lord**
8. **Sovereign**
9. **Saint**
10. **Ascendant**
11. **Divine / Authority-bearing stages**

Not every Class uses every exact title.

Some Class families use thematic equivalents.

Examples:

- Mage Apprentice
- Knight Trainee
- Warrior Initiate
- Assassin Adept
- Rune Scholar
- Flame Lord
- Sword Saint

The System may rename Class Stages to suit the path.

---

# 8. Early-Class Naming Convention

At the current story era, most of the 200 Awakened are still in early Class development.

Therefore:

- Fire Mage → **Fire Mage Apprentice**
- Ice Mage → **Ice Mage Apprentice**
- Lightning Mage → **Lightning Mage Apprentice**
- Swordsman → **Swordsman Apprentice**
- Ember Knight → **Trainee Ember Knight**
- Earthen Warrior → **Earthen Warrior Apprentice** or equivalent
- Healer → **Healer Apprentice**

The **core Class identity** is Fire Mage, Ice Mage, Ember Knight, etc.

The appended stage indicates how far that Class has matured.

Example:

`Fire Mage Apprentice`

means:

**Class Family:** Fire Mage  
**Current Class Stage:** Apprentice

Later:

`Fire Mage Adept`

then potentially an evolution:

`Inferno Arcanist Apprentice`

The new evolved Class can begin at a new Class Stage depending on the evolution.

# 9. Class Evolution

Classes are not static.

They evolve when the individual has sufficiently developed the path.

Evolution can depend on:

- Level
- Tier
- Star Rating
- Skill mastery
- affinity depth
- Class Stage
- major achievements
- Class Quests
- combat history
- weapon specialization
- Bloodline awakening
- Trait evolution
- Race evolution
- Law comprehension
- Divinity
- hidden conditions
- individual choices

## Example — Fire Magic Path

`Fire Mage Apprentice`
→ `Fire Mage Adept`
→ `Flame Arcanist`
→ `Inferno Magus`
→ `Lord of the Burning Sky`
→ higher Mythic/Divine paths

## Alternative Fire Path

A Fire Mage who develops swordsmanship heavily may branch:

`Fire Mage Apprentice`
→ `Flameblade`
→ `Ashen Knight`
→ `Solar War Saint`

The System rewards actual development rather than forcing everyone through identical trees.

# 10. Branching Evolution

One Class can produce multiple evolution branches.

## Warrior Example

`Warrior Apprentice`

Possible branches:

- Guardian
- Berserker
- Duelist
- Knight
- Weapon Master
- Mana Warrior

An Earth-affinity Guardian may become:

`Guardian`
→ `Stone Guardian`
→ `Adamant Bastion`
→ `Mountain Sovereign`

A Fire-affinity Knight may become:

`Knight`
→ `Ember Knight`
→ `Inferno Knight`
→ `Solar War Saint`

---

# 11. Hybridization

Characters should not accumulate dozens of unrelated permanent combat Classes.

Instead, compatible paths should usually:

- merge
- evolve
- synthesize
- branch into hybrid Classes

Example:

Instead of permanently holding:

- Swordsman
- Lightning Mage
- Wind Mage

the System may eventually produce:

`Stormblade`

then:

`Tempest Swordmaster`

then:

`Heavenstorm Sword Saint`

This keeps Status windows clean and makes the Class reflect the person's actual identity.

---

# 12. Multiple Classes

Normal rule:

> **One Primary Class**

Exceptional cases may allow:

- one Subclass
- a Profession
- a Divine Class
- a dual-Class state
- Bloodline Class
- Race-linked Class
- System irregularity

A Subclass should complement the Primary Class rather than replace it.

Professions do not count as normal combat Classes.

---

# 13. Class Stat Growth

Class stat bonuses are added **per Level** on top of Personal Rank growth.

The exact amount depends on rarity and specialization.

## Recommended Class Growth Budget

This is the **total additional Attribute growth per Level** available to the Class.

| Class Rarity | Typical Bonus Stats / Level | General Power |
|---|---:|---|
| **Common** | +1 to +2 total | Basic specialization |
| **Uncommon** | +2 to +3 total | Noticeable advantage |
| **Rare** | +3 to +5 total | Strong specialized growth |
| **Epic** | +5 to +8 total | Exceptional growth |
| **Legendary** | +8 to +12 total | Extremely high |
| **Mythic** | +12 to +18 total | World-class |
| **Unique** | Variable | Depends on Class concept |
| **Divine** | +20+ or special scaling | Divine authority-level growth |

> [!warning]
> These are **Class growth bonuses only**.
>
> Personal Rank growth still applies separately.
>
> Extremely high-rarity Classes should not simply dump all power into raw stats. Part of their value should come from mechanics, passives, Skills, efficiency, and evolution potential.

# 21. Rarity Should Affect More Than Stats

A higher-rarity Class should not simply mean:

> bigger stat numbers

It should also provide more sophisticated mechanics.

## Common
- simple stat specialization
- minor efficiency bonus
- one basic passive

## Uncommon
- stronger specialization
- better Skill efficiency
- one meaningful mechanic

## Rare
- strong synergy
- multiple effects
- distinctive passive
- stronger evolution branches

## Epic
- major specialization
- strong Class Skills
- advanced combat mechanic
- substantial growth

## Legendary
- exceptional growth
- unique combat systems
- powerful hybridization
- rare Class Quests
- major evolutionary potential

## Mythic
- world-class mechanics
- possible Law/Domain interaction
- extreme evolution ceiling
- major influence on battlefield or environment

## Unique
- custom rules
- may create mechanics the standard Class catalogue does not possess
- can be born from Bloodlines, impossible achievements, or System irregularities

## Divine
- interacts with Divinity
- Laws
- Domains
- Authorities
- divine vessels
- may eventually transcend ordinary Class structure

# 22. Class Stage Advancement

Class Stage should not automatically rise every fixed number of Levels.

Instead, it should evaluate:

- Skill mastery
- use of Class mechanics
- relevant achievements
- combat performance
- affinity development
- Tier
- Level
- Class Quests

Example:

[ CLASS ADVANCEMENT AVAILABLE ]

**Fire Mage Apprentice**
→ **Fire Mage Adept**

Requirements:
- Fire Skill mastery threshold reached
- complete one Fire Class Quest
- defeat a qualifying enemy using Fire magic
- demonstrate stable Fire Mana shaping

This makes Class growth earned rather than automatic.

---

# 23. Evolution vs Stage Advancement

These are different.

## Stage Advancement

Same Class, greater mastery.

Example:

`Fire Mage Apprentice`
→ `Fire Mage Adept`
→ `Fire Mage Expert`

## Class Evolution

The Class itself changes into a superior or specialized path.

Example:

`Fire Mage Expert`
→ `Flame Arcanist Apprentice`

The evolved Class may begin a new internal stage progression.

# 25. Alok — Special Class Rule

Alok's first Class should behave differently from normal Judgment.

The Judgment System believes that better performance should produce:

- more Class options
- higher maximum rarity
- more specialized choices

However, the System has already been tracking:

- Alok's Divine Personal Rank
- Bloodlines
- celestial-violet Mana
- Lightning and Blood Affinities
- Regeneration
- combat behavior
- protective instincts
- Skill creation
- titles
- achievements
- unusual Tier progression
- Judgment performance

When the Judgment attempts to generate his Primary Class:

1. the normal catalogue is searched
2. no complete Class match exists
3. hidden/sealed/hybrid catalogues are searched
4. his Bloodline activates
5. an unregistered Class Authority manifests
6. the System extracts and interprets the Class
7. the System creates a System-compatible framework
8. the Class is registered for the first time

Therefore:

> Alok's Primary Class is **not truly selected from the existing catalogue**.

It is pulled from his Bloodline and formalized by the System.

The Class effectively **did not exist in the System before Alok**.

# 26. Alok — Judgment Compensation

Because Alok earned a normal high-quality Class selection through Judgment performance but the Bloodline Class overrides that selection right, the System compensates him.

Current intended compensation:

- **Premium Random Draw Ticket ×1**
- **Subclass Selection Right ×1**

The Premium Ticket is not a normal Judgment reward.

It is classified as:

**System Irregularity Compensation**

The Subclass preserves Alok's earned agency.

Conceptually:

> **Primary Class = inherited destiny / Bloodline**
>
> **Subclass = Alok's chosen specialization**

# 27. Subclass Rules

A Subclass should:

- complement the Primary Class
- provide smaller stat growth than the Primary Class
- provide specialized Skills/passives
- allow player agency
- potentially merge with the Primary Class later

Suggested Subclass growth:

| Rarity | Bonus Stats / Level |
|---|---:|
| Common | +1 |
| Uncommon | +1 to +2 |
| Rare | +2 to +3 |
| Epic | +3 to +5 |
| Legendary | +5 to +7 |
| Mythic | +7 to +10 |

A Subclass should generally contribute less raw growth than an equivalent Primary Class because it is supplemental.

# 29. Balancing Rules

1. **Personal Rank remains the main universal growth engine.**
2. **Class growth is additive specialization.**
3. High rarity should provide mechanics, not only raw stats.
4. Class rarity does not equal current combat strength.
5. A Legendary Class user can still lose to a stronger, higher-Tier Common-Class user.
6. Tier remains the measure of realized vessel strength.
7. Star Rating remains mana-core architecture.
8. Affinity remains independent.
9. Skills remain broadly learnable.
10. Class Stage measures mastery of the current Class.
11. Class Evolution changes the Class itself.
12. Hybridization is preferred over endless Class stacking.
13. Class growth must respect vessel Attribute limits.
14. Stat growth exceeding current vessel capacity is stored as unrealized growth rather than deleted.
15. Rare/unique Classes should feel earned.
16. The first Judgment should strongly reflect the individual's actual history.
17. Later evolutions should become increasingly personalized.
18. At Divine levels, Classes may eventually become Paths, Domains, Laws, or Authorities.

# 32. Current Canon Summary

**Class = specialization and evolution.**

**Personal Rank = universal growth potential.**

**Tier = realized vessel strength.**

**Level = accumulated System progression.**

**Star Rating = Mana-core architecture.**

**Affinity = innate elemental conversion characteristic.**

**Skill = an ability.**

**Bloodline = inherited power/authority.**

**Class Stage = mastery of the current Class.**

**Class Evolution = transformation into a superior or specialized Class.**

These systems interact—

but must remain mechanically distinct.
