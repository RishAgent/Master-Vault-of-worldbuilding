# Shadow Repository — Alok Aeonmorta

> [!summary]
> **Shadow Repository** is Alok's manually reconstructed shadow-necromancy system, learned by studying the architecture of Rajan's **Shadow Necromancer** Class through the Class Codex.
>
> It is **not** an Eternal Legion ability and does **not** use, imprison, copy, or contain the target's soul.
>
> A Shadow is a **Mana construct** created from the residual combat imprint, shape, and shadow/death residue left by a slain being.

---

# 1. Core Principle

Alok does **not** possess the Shadow Necromancer Class.

Instead:

1. the Class Codex records and analyzes Shadow Necromancer architecture;
2. Alok studies the underlying magical principles;
3. he manually reproduces the shadow-extraction process;
4. his **Sovereign of Eternal Cycle** Class modifies and stabilizes the result.

This is possible because magic itself is **not Class-locked**.

Classes provide:

- optimized pathways
- automatic Skill support
- efficiency
- growth bonuses
- evolution routes
- System assistance

But sufficiently knowledgeable practitioners may reproduce the underlying magic manually.

---

# 2. Shadow Repository

## Name

# Shadow Repository

**Rarity:** Rare — current working rarity  
**Type:** Shadow / Death Mana Construct Magic  
**Origin:** Reverse-engineered from Shadow Necromancer architecture  
**Class Influence:** Sovereign of Eternal Cycle  
**Soul Requirement:** None

---

# 3. What a Shadow Is

A stored Shadow is:

- a Mana construct
- shaped from residual death/shadow imprint
- modeled after a slain being
- capable of reproducing part of the target's combat form
- sustained by Alok's Shadow Repository

A Shadow is **not**:

- the original being
- the original soul
- a resurrected person
- an Eternal Legion member
- conscious in the same sense as the original
- a container for the dead person's memories

The original soul remains completely separate.

---

# 4. Creation Process

To create a Shadow, Alok requires a sufficiently intact residual imprint from a slain target.

Possible sources include:

- corpse
- fresh death residue
- lingering Mana signature
- strong shadow imprint
- preserved combat echo

The better the remains / imprint, the better the resulting Shadow.

## Creation Cost

Creating a Shadow **does cost Mana**.

Exact creation cost is currently **TBD** and should scale according to:

- target Tier
- target complexity
- racial traits
- retained combat abilities
- condition of the corpse / imprint
- Alok's mastery
- Shadow Repository evolution

---

# 5. Summoning Cost

Once successfully created and stored:

# Summoning a stored Shadow costs no Mana.

The construct has already been formed and anchored within the Repository.

It may be:

- summoned
- recalled
- summoned again
- repositioned through dismissal and resummoning

without paying a repeated summoning cost.

This remains true until the Shadow is:

- destroyed
- permanently released
- deliberately erased

---

# 6. Dismissal

A Shadow may be dismissed voluntarily.

Dismissal:

- does not destroy the construct
- returns it to the Shadow Repository
- costs no Mana
- allows it to be summoned again later

This makes stored Shadows highly efficient persistent combat constructs.

---

# 7. Destruction

If a Shadow is completely destroyed in combat:

- its active Mana body is destroyed;
- the Shadow is lost permanently under the current version of the Skill.

Alok must create a new Shadow from another valid target if he wants a replacement.

A future evolution may allow damaged or destroyed Shadow patterns to be reconstructed.

---

# 8. Initial Storage Capacity

Because Alok's soul architecture is massively superior to a normal beginner Shadow Necromancer's storage framework, his version begins with a much larger capacity.

## Working Initial Capacity

# 100 Shadows

Reason:

- Sovereign of Eternal Cycle is a Unique Divine Life/Death/Soul Class;
- Alok already possesses a vast metaphysical Soul Space;
- his soul can safely anchor far more construct patterns than the standard Class architecture;
- Death Authority naturally stabilizes the stored imprints.

This does **not** mean the Shadows are stored inside the Eternal Legion itself.

The Shadow Repository is a separate internal construct-space / archive attached to Alok's soul architecture.

# 10. Retained Abilities

A Shadow may retain portions of the original target's combat capability.

Potentially retained:

- physical fighting style
- weapon usage
- movement patterns
- instinctive racial combat abilities
- simple Mana techniques
- some Skills whose operation does not require the original soul or bloodline authority

Generally not retained automatically:

- Divine authority
- true soul-based abilities
- unique bloodline inheritance
- personal memories
- personality
- high-level conceptual Laws
- abilities requiring a living organ or bloodline structure that the Shadow cannot reproduce

Retention quality depends on Shadow Repository mastery.

---

# 11. Power Level of a Shadow

A newly created Shadow does not automatically equal the original target at full power.

Its combat strength should depend on:

- target strength at death
- quality of the residual imprint
- Alok's mastery
- Shadow Repository rarity/evolution
- Alok's Tier
- available construct quality

## Working Principle

Early Shadows should retain only a portion of the original being's effective combat power.

Exact percentage is **TBD**.

This prevents Shadow Repository from immediately becoming a perfect-copy army.

# 17. Canon Locks

- Shadow Repository is separate from the Eternal Legion.
- Shadows are **Mana constructs**, not souls.
- A Shadow does not contain the original person's consciousness or memories.
- Creating a new Shadow costs Mana.
- Once created and stored, summoning that Shadow costs **no Mana**.
- Dismissing a Shadow costs **no Mana** and returns it to storage.
- A stored Shadow may be summoned repeatedly until it is destroyed or permanently released.
- Current rule: complete destruction permanently destroys that Shadow.
- Initial working storage capacity: **100 Shadows**.
- Alok's Sovereign of Eternal Cycle greatly improves capacity, stability, retention, and command.
- Magic is not Class-locked.
- Alok learned the system by studying Rajan's Shadow Necromancer Class through the Class Codex.
- Alok does not possess the Shadow Necromancer Class.
- Shadow Repository is a disposable-army system.
- Eternal Legion remains a persistent-person system.
