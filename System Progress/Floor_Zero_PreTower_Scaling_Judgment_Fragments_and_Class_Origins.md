# Floor Zero Pre-Tower Scaling, Judgment Fragments, and Class Origins

> [!summary]
> This note locks the working framework for Level caps before Tower entry, Tier expectations at Level 25, Alana as the Human scaling anchor, Judgment Fragment rarity, progressively harder Fragment Trials, hereditary Primary Classes, Alok's unique 43-hour completion, and Floor Zero multiversal character design.

---

# 1. Pre-Tower Level Cap

For normal Awakened who have not yet become Tower Players:

# **Maximum Level: 25**

The First Generation Judgment Champions are an exception.

Their special planetary Judgment process allowed them to reach:

# **Level 30**

Therefore:

- normal Floor Zero entrant = Level 25 maximum
- First Generation Judgment Champion = Level 30 maximum before Player progression
- Level does not directly define Tier
- actual Tier depends on attributes, Race, Personal Rank, Classes, bloodline, resources, achievements, and external growth

# 6. Superior Races

Superior races may sit roughly one substage above an equivalent Human.

Royal, supreme, or ancient bloodlines may sit two or more substages higher.

## Valkyrie

- strong physical and martial racial growth
- S-Rank elite: Intermediate Bronze
- Mythic royal prodigy: Advanced Bronze
- exceptional ceiling: Peak Bronze

## Angel

- naturally high INT / VIT
- strong Mana Core
- Light affinity
- flight
- S-Rank elite: Intermediate Bronze
- Mythic noble: Advanced Bronze
- Demi prodigy: Peak Bronze

## Civilized Demon

Highly variable by bloodline.

- ordinary Demon: around Human or somewhat superior
- high noble: significantly superior
- S-Rank noble: Beginner–Intermediate Bronze
- Mythic noble: Advanced Bronze
- Demi ancient lineage: Peak Bronze

## Dragonoid

Among the strongest common Floor Zero races.

Advantages:

- superior STR
- superior VIT
- better Mana Core
- strong affinity
- draconic bloodline
- high INT potential

Expected:

- S-Rank royal Dragonoid: Intermediate–Advanced Bronze
- Mythic royal Dragonoid: Advanced–Peak Bronze
- Demi supreme-lineage prodigy: Peak Bronze → rare Beginner Silver

## Demigod

Depends heavily on divine parentage and inherited bloodline.

- strong Demigod: Advanced Bronze
- Mythic / Demi prodigy: Peak Bronze
- exceptional monster: Beginner Silver before Floor Zero

Silver before Floor Zero must remain rare.

# 9. Class Rarity and Access

Being Classed is itself uncommon.

A person does not automatically receive a Class at a given Level.

They need:

# **A Judgment Fragment**

Judgment Fragments may come from:

- monster hunting
- Gate activity
- quests
- rare drops
- organizational stockpiles
- military distribution
- noble / family reserves
- market purchase
- inheritance

Therefore:

- many Awakened may have no Class
- one Class is the normal serious-Awakened benchmark
- two Classes is elite
- three Classes is rare prodigy territory
- four or more is exceptional anomaly territory

---

# 10. Why the Trial Generation Had Better Classes

The First Generation Trial cohort had unusually strong Class quality because they were:

- trained from a young age
- prepared for monster combat
- exposed to dangerous environments
- actively hunting monsters
- completing quests
- receiving organizational support
- deliberately seeking Judgment Fragments
- repeatedly entering Fragment Trials

Therefore their Class distribution is not representative of normal Awakened society.

They contain more Uncommon, Rare, and Epic Classes than the general population.

# 11. Judgment Fragment Trial Rules

Judgment Fragment Trials are personal performance evaluations.

They judge more than survival time.

Likely factors include:

- survival duration
- combat performance
- enemy quality
- objectives completed
- adaptability
- Class compatibility
- efficient Skill use
- current vessel capability
- current number of Classes
- prior Fragment success

The reward is not purchased or guaranteed.

Money can buy:

- fragments
- tutors
- equipment
- healing
- preparation

Money cannot buy:

# **Epic Class guaranteed**

---

# 12. Progressive Trial Difficulty

Each successive Fragment Trial becomes substantially harder.

The Trial scales against the claimant.

## First Fragment Trial

Calibrated for:

- no Class
- current Level
- current vessel

## Second Fragment Trial

Calibrated assuming:

- one existing Class
- increased Level
- improved Skills
- better combat capability

## Third Fragment Trial

Calibrated assuming:

- two existing Classes
- much higher Level
- stronger Skill set
- more combat experience

Later Trials are not merely the same Trial with stronger monsters.

They test whether the claimant can exceed what their current build should already allow.

# 16. Class Origin Types

There are three major Class origins.

## 16.1 Fragment-Acquired Classes

The normal route:

1. obtain a Judgment Fragment
2. enter a personal Trial
3. perform
4. receive a compatible Class

Class rarity depends on:

- performance
- compatibility
- existing Classes
- vessel quality
- potential
- Trial result

---

## 16.2 Bloodline / Racial Primary Classes

Some races and major bloodlines naturally carry a hereditary:

# **Primary Class**

or:

# **Class Seed**

It may remain dormant until:

- Awakening
- a Level threshold
- first Fragment use
- Tier breakthrough
- bloodline activation
- specific catalyst

A Fragment may:

- awaken it
- reveal it
- refine it
- evolve it
- stabilize it
- tailor it to the individual

Possible examples:

- Supreme Dragonoid lineage
- high Angelic bloodline
- ancient Demon nobility
- Valkyrie royal line
- Demigod lineage
- Divine bloodline

---

## 16.3 Unique System-Generated Classes

Very rare cases exist where the claimant does not fit an existing Class template.

The System may create a new Class based on:

- soul
- bloodline
- affinities
- Trial performance
- innate authorities

Alok is the clearest example.

# 18. Primary Class Principle

The Primary Class represents the deepest expression of identity.

For most people:

> Primary Class is Fragment-earned.

For some:

> Primary Class is inherited through Race or bloodline.

For anomalies like Alok:

> Primary Class is synthesized by the System from bloodline + soul + affinities + Trial performance.

Secondary Classes are more often Fragment-earned and reflect learned paths.

# 31. Final Canon Principles

## Level / Tier

- normal pre-Tower cap = Level 25
- Judgment First Generation cap = Level 30
- Tier is vessel / attribute-based, not Level-based
- Human Level 25:
  - Advanced Iron good
  - Peak Iron elite
  - Beginner Bronze exceptional
  - Intermediate Bronze heavily resourced / prodigious
  - Advanced Bronze anomalous

## Classes

- being Classed is not automatically common
- Judgment Fragments must be acquired
- strong Classes cannot simply be purchased
- later Fragment Trials become progressively harder
- multiple Epic Classes are genuinely rare
- Trial Generation had stronger average Classes because they were deliberately trained and prepared

## Alana

- S Rank Human
- Level 25 Beginner Bronze
- 2 Epic + 1 Rare
- Fragment Trial history:
  - Level 5 / ~30 min → Epic
  - Level 20 / >1 hr → Epic
  - third Trial / ~1 hr 40 min → Rare
- current Advanced Bronze due Judgment AP and resources
- near upper limit of Advanced Bronze

## Bloodlines

- some races / bloodlines carry hereditary Primary Classes
- hereditary Class rarity depends on lineage quality
- Fragments can awaken / refine hereditary Classes
- powerful heirs do not need many Fragment Classes to be strong

## Alok

- only one Fragment Trial
- reached absolute end at ~43 hours
- originally eligible for 1 Divine + 1 Mythic
- Aeonmorta bloodline interfered
- System generated unique Divine Primary Class:
  - **Sovereign of Eternal Cycle**

# 32. Design Philosophy

> **Race determines baseline.**  
> **Personal Rank determines growth potential.**  
> **Primary Class determines core path.**  
> **Secondary Classes broaden specialization.**  
> **Judgment performance determines earned Class quality.**  
> **Bloodline can provide inherited Class architecture.**  
> **Resources improve development but cannot guarantee Class rarity.**  
> **Tier measures the actual vessel.**  
> **Floor Zero matchmaking evaluates the whole build.**

This prevents every important character from becoming a three-Epic-Class monster while preserving genuinely exceptional prodigies.
