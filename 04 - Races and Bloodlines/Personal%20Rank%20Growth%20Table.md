# Personal Rank Growth Table

## Purpose

This note tracks the permanent Attribute growth granted by **Personal Rank** whenever an Awakened levels up.

Personal Rank represents growth potential and efficiency. It is separate from:

- Tier
- Level
- Star Rating
- Class
- Affinity
- Race
- Traits
- Bloodlines
- equipment
- titles
- breakthrough reconstruction

Class growth is added **on top of** Personal Rank growth.

# Important Rule

Personal Rank and Class growth are independent.

Example:

A B-Rank unit with a Class granting:

- STR +1
- AGI +1
- VIT +1

would receive, every Level:

### B-Rank Personal Growth

- STR +3
- AGI +3
- VIT +3
- INT +4
- Free AP +5

### Class Growth

- STR +1
- AGI +1
- VIT +1

### Combined Automatic Growth

- STR +4
- AGI +4
- VIT +4
- INT +4
- Free AP +5

This distinction should remain consistent for all future characters and summons.
