# Draconic Races - Index

This folder is the **V4 rewrite of the old Dragon Lore Vault**.

> [!important] Core distinction
> **Dragons** and **Dragonoids** are sibling draconic races descended from the same ancestral draconic source.
>
> - Dragons begin as immense **beasts of magic** and evolve toward civilization, humanoid manifestation, structured magic and Classes.
> - Dragonoids are born as a **civilized humanoid race**, use Classes and complex magic naturally, and evolve toward unlocking their complete draconic body and ancestral authority.
> - **Platinum Tier** is the normal convergence transition. At **Diamond Tier**, both routes normally complete Draconic Ascension into a higher draconic existence. Origin remains historically relevant, but neither is simply Dragon nor Dragonoid anymore.

## V4 progression compatibility

Draconic beings use the same universal systems as everyone else:

- **Personal Rank:** F → E → D → C → B → A → S → SS → SSS → Divine
- **Tier:** Ordinary → Iron → Bronze → Silver → Gold → Platinum → Diamond → Supreme → Noble → Baron → Count → Duke → King → Emperor → Sovereign → Transcendent → Demigod → Divine
- **Substages:** Beginner → Intermediate → Advanced → Peak
- **Race:** Dragon, Dragonoid, or higher evolved draconic Race
- **Bloodline:** inherited draconic lineage
- **Affinity:** elemental/conceptual Mana characteristics
- **Stars:** Mana-core architecture
- **Class:** specialization path; common among Dragonoids, less common among immature wild Dragons

The old Dragon Vault's Iron/Bronze/Silver/Gold **Bloodline Rank** ladder has been retired. Those words now refer only to V4 **Tier** where appropriate.
